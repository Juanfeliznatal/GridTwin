# GridTwin — versão 3.9

## Como abrir

1. Extraia a pasta `jogo1` completa.
2. Abra `index.html` no navegador, mantendo a pasta `assets/` no mesmo local.
3. Leia o arquivo **`Guia_Rapido_GridTwin_v3_9_Uma_Pagina.pdf`** para aprender a jogar.

O guia explica em uma página os objetivos, sensores, sobrecargas, telemetria automática, habilidades e atalhos.

O código e as mecânicas do jogo foram preservados nesta edição; somente a documentação foi atualizada.
